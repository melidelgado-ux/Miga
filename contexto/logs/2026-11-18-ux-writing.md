# Ajustes de UX writing

- **Estado:** cambios locales aplicados y verificación de tipos aprobada.
- **Alcance:** textos de invitación, formularios, filtros, búsqueda, tarjetas y detalle.
- **Criterios aplicados:** aclarar el límite del enlace de demo, nombrar estados y
  acciones con precisión, unificar el voseo rioplatense y ampliar unidades visibles.
- **Validación:** `npm run lint` (`tsc --noEmit`) aprobado. Git no está disponible en
  esta carpeta, por lo que no se pudo revisar un diff ni determinar cambios previos.
- **Fuentes:** componentes en `src/` y límites actuales descritos en `README.md` y
  `PRD.md`.
